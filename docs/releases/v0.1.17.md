# @dsh-bio/dsh-bio-gem v0.1.17

> **主题**：默认值通用化与公开信息审计修复。
> 基因组尺度代谢模型（GEM）构建插件：基因组输入 → 构建 → 验证 → 补洞 → 出报告（标准 SBML + 模型卡）。

## 修复与改进

**默认值通用化（面向所有用户）**
- 资源路径默认值不再绑定开发机目录：解释器/工具与参考资源改为**插件数据目录 + 环境变量**优先
  （`GEM_GAPSEQ_DB` / `GEM_DIAMOND` / `GEM_WHITELIST_DB_DIR` / `GEM_UNIVERSAL_MODEL` / `GEM_INX_MODEL`），
  缺失时给出可操作提示而非静默失败。
- BiGG 模型下载的代理回退改为读取**环境变量代理**（`HTTP_PROXY` / `HTTPS_PROXY` / `ALL_PROXY`），
  不再固定本机端口；描述与实现一致。

**测试与文档**
- 回归脚本资产配置显式化：`--assets-root` 或 `DSH_BIO_GEM_ASSETS` 指定模型资产；缺资产时相关检查 SKIP（不误报为回归失败）。
- 文档一致性：生长值单位口径说明（归一化 biomass 为 1/h；一般反应通量为 mmol/gDW/h）、工具计数、
  架构文档状态与内部代号清理、基准报告路径通用化。

## 安装

```sh
npx -y @deepseek-ai/dsh plugin --profile web add @dsh-bio/dsh-bio-gem
```

桌面端（0.2.0+）：用桌面端自带 CLI（`--profile desktop`）或应用内「插件」页安装。
分析用 Python（cobra）优先复用 dsh-bio-genie 自举环境；未装 genie 时见 README 第 2 节。

- 其余边界见 v0.1.12 清单。
