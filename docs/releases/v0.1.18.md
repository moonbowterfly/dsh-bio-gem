# @dsh-bio/dsh-bio-gem v0.1.18

> **主题**：公开信息审计复核修复批次（含小型行为修复）。
> 基因组尺度代谢模型（GEM）构建插件：基因组输入 → 构建 → 验证 → 补洞 → 出报告（标准 SBML + 模型卡）。

## 修复与改进

**行为修复**
- BiGG 模型下载的代理回退：显式将 `ALL_PROXY` 映射到 http/https（此前仅声明支持、实际未生效）；直连失败时按系统/环境代理重试。
- 白名单构建入口守卫：`GEM_GAPSEQ_DB` 未配置或无效时在任何文件操作前给出可操作错误（生产调用链同样受控，不再隐式使用相对目录）。
- 回归脚本解释器默认值沿用 `DSH_HOME`（与生产解析规则一致；显式 `GEM_PYTHON` 仍最高优先）。

**文档与一致性**
- 架构文档：去内部阶段代号与决策史；工具契约表补 `gem_quality` / `gem_sample`（23 工具 / 23 op）；生长/通量单位口径统一（归一化 biomass 为 1/h；一般通量为 mmol/gDW/h）。
- 计数一致性：README 英文段 22 工具（除 build 外）；中文标题 23。
- 过程叙事中性化：代码注释与工具返回文案中的开发阶段标签、调用经历记录全部清除（保留判据依据与错误条件）。

## 安装

```sh
npx -y @deepseek-ai/dsh plugin --profile web add @dsh-bio/dsh-bio-gem
```

桌面端（0.2.0+）：用桌面端自带 CLI（`--profile desktop`）或应用内「插件」页安装。
分析用 Python（cobra）优先复用 dsh-bio-genie 自举环境；未装 genie 时见 README 第 2 节。
